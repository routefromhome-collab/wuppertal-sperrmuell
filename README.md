# Шпера Wuppertal: Telegram Mini App

Карта и список улиц, где жители выставляют Sperrmüll (крупногабаритный мусор) в ближайшие 7 дней.
Пользователь вводит дату: она становится днём 1, дальше идут ещё 6 дней.

> **Правило дат D-1 (намеренное).** AWG вывозит 30 ноября → жители выставляют 29 ноября →
> улица показывается в списке **29-го**. В данных хранятся «сырые» даты вывоза AWG, сдвиг
> применяется в одном месте на каждый язык: `sperrmuell/dates.py` и `web/js/dates.js` (оба покрыты тестами).

## Архитектура

```
GitHub Actions (Python)                        GitHub Pages (чистый JS, без сборщика)
┌──────────────────────────┐   commit JSON    ┌───────────────────────────────────────┐
│ build_schedule  ─ AWG ──►│ web/data/        │ index.html + js/*.js + Leaflet (CDN)  │
│ geocode ─ Nominatim ────►│  schedule.json ─►│ окно 7 дней, D-1, карта, маршруты     │
│ publish ─► Telegram-канал│  coords.json     │ Telegram WebApp SDK (тема, MainButton)│
└──────────────────────────┘  streets.json    └───────────────────────────────────────┘
```

Главное отличие от старого `main.py`: один запрос на улицу отдаёт календарь целиком, поэтому парсер
забирает **все даты сразу**, а окно в 7 дней считает клиент. Запросов к AWG примерно в 7 раз меньше,
записи младше 25 дней не перезапрашиваются, а ввод даты не требует нового парсинга.

| Что | Где |
|---|---|
| Парсер AWG (чистые функции + тонкий клиент) | `sperrmuell/awg.py` |
| Сборка расписания, защита от сбоев | `sperrmuell/build_schedule.py` |
| Геокодирование (Nominatim → Photon, рамка Wuppertal) | `sperrmuell/geocode.py` |
| Публикация в канал из приложения (Worker, права админа) | `worker/src/index.js`, `web/js/admin.js` |
| Публикация в канал через GitHub Actions (запасной путь) | `sperrmuell/publish.py` |
| Текст поста для Worker (общий с приложением) | `web/js/message.js` |
| TSP-маршруты, ссылки Google Maps по 20 точек | `sperrmuell/routing.py` и `web/js/routing.js` |
| Mini App | `web/` |

## Первый запуск

1. Создайте репозиторий (например `wuppertal-sperrmuell`), загрузите содержимое этой папки.
2. **Settings → Pages → Source: GitHub Actions.**
3. **Settings → Secrets and variables → Actions:**
   - secrets: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `TELEGRAM_ADMIN_CHAT_ID`
   - variable: `MINIAPP_URL` (ссылка на Mini App вида `https://t.me/<бот>/<имя_приложения>`, нужна после шага 6)
4. **Actions → Update schedule → Run workflow**, сначала с `limit = 20` (испытание), затем без лимита.
   Первый полный прогон геокодирует ~370 улиц, которых нет в сидовом кэше (~10 мин, Nominatim 1 запрос/сек).
5. Дождитесь **Deploy Pages**: приложение появится на `https://<аккаунт>.github.io/<репозиторий>/`.
6. В @BotFather: `/newapp` (или Bot Settings → Menu Button) и укажите этот URL.
7. Публикация в канал из приложения: см. раздел «Публикация из приложения» ниже. Запасной путь без приложения:
   **Actions → Publish → Run workflow** (`start_date`, сначала с `dry_run = true`).

## Публикация из приложения (для админа)

Токен бота нельзя держать в браузере, поэтому отправляет маленький Cloudflare Worker (бесплатный тариф подходит).
Приложение показывает админу кнопку 📣 рядом с заголовком: превью 7 дней, выбор дней, подтверждение, отправка.
У остальных пользователей кнопки нет, а Worker всё равно проверяет права сам.

Как это защищено: Worker проверяет подпись Telegram (`initData`, HMAC по токену бота), срок её действия (час для публикации)
и что ваш Telegram ID есть в `ADMIN_IDS`; принимает запросы только с `ALLOWED_ORIGIN`; публикует **один день за запрос**;
не даёт отправить дату, на которую календарь AWG ещё не опубликован (иначе вышел бы ложный «выходной»);
с KV `STATE` повтор того же запроса не дублирует пост.

Настройка (один раз):

1. Аккаунт на cloudflare.com (бесплатно). В `worker/wrangler.toml` проверьте `DATA_BASE_URL`, `ALLOWED_ORIGIN`, впишите `MINIAPP_URL`.
2. Из каталога `worker/`: `npx wrangler login`, затем секреты:
   ```bash
   npx wrangler secret put BOT_TOKEN       # токен бота; бот должен быть админом канала с правом публикации
   npx wrangler secret put CHANNEL_ID      # @schwebezeit или числовой id
   npx wrangler secret put ADMIN_IDS       # ваш Telegram ID (узнать: @userinfobot), несколько через запятую
   npx wrangler secret put ADMIN_CHAT_ID   # необязательно: уведомление «кто и что опубликовал»
   ```
3. (Рекомендуется) защита от двойной отправки: `npx wrangler kv namespace create STATE`, вставьте выданный id в раскомментированный блок `[[kv_namespaces]]`.
4. `npx wrangler deploy`. Адрес вида `https://sperrmuell-admin.<аккаунт>.workers.dev` впишите в `web/config.js` (`API_URL`) и закоммитьте.
   Дальнейшие обновления разворачивает workflow **Deploy Worker** (secrets `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`).
5. Откройте приложение из Telegram: рядом с заголовком появится 📣. В обычном браузере вне Telegram она не появится: нужна подпись Telegram.

Формат поста тот же, что в рабочем `main.py`: заголовок «Шпера 29 November 2026», улицы по алфавиту со ссылками `map`,
оптимизированный маршрут по частям (до 20 точек), строка «Полная карта» (теперь ведёт в Mini App) и `#шпера`.
Номера домов в пост не выводятся (как и раньше), но в приложении видны.

## Локальная разработка

```bash
pip install -r requirements.txt pytest && python -m pytest -q   # 20 тестов
npm test                                                          # 8 тестов
python -m sperrmuell.build_schedule --only "Bachstr" --force --dry-run
cd web && python -m http.server 8000                              # http://localhost:8000
```

Ссылка с датой: `https://t.me/<бот>/<приложение>?startapp=2026-11-29` откроет приложение на этой дате.

## Что осталось проверить на реальных данных

- **Фикстуры `tests/fixtures/awg_*.html`: настоящие страницы AWG** (сняты 2026-11-23 из артефакта Actions): календарь,
  выбор дома, похожие улицы, «нет такой улицы». `legacy_*.html` синтетика для запасного разбора старой вёрстки.
  `tests/test_parity_main3.py` сверяет разбор с логикой последнего рабочего `main.py` по каждому дню каждой страницы.
  Если вёрстка AWG изменится, сборщик не затрёт данные (порог сбоев 5% и не меньше 3 улиц, код выхода 2, сообщение в админ-чат).
- **Календари отдельных домов** (`action=list`) проверены на странице выбора дома, но сами страницы домов в испытаниях
  не сохранялись: первый полный прогон их проверит; при сбое HTML окажется в артефакте `awg-debug-html`.
- Leaflet и Telegram SDK подключаются с CDN без SRI-хешей; для усиления защиты добавьте `integrity`
  или положите файлы в `web/vendor/`.
- Тайлы `tile.openstreetmap.org` годятся для небольшой аудитории; при росте нагрузки перейдите на
  собственного провайдера тайлов (политика использования OSM).
